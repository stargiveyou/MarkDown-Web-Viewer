# agent-work — 에이전트 작업 공유 폴더

**진행 중**인 작업의 인터페이스 합의와 중간 산출물을 공유하는 곳이다.
완료 기록은 [../complete-work/](../complete-work/), 검증 결과는 [../valid/](../valid/).

## 파일명 규칙

| 형식 | 용도 |
|------|------|
| `contract-stage-<N>.md` | 해당 단계의 확정 API 계약 + 공유 타입 (tech-lead 소유) |
| `frontend-stage-<N>-<topic>.md` | 프론트가 공유해야 할 결정·요청 |
| `backend-stage-<N>-<topic>.md` | 백엔드가 공유해야 할 스키마·결정 |
| `security-stage-<N>-<topic>.md` | 보안 스펙·스텁·위협 모델 |

## 운영 규칙

1. 에이전트는 작업 착수 전 이 폴더의 **해당 단계 계약 문서를 먼저 읽는다**.
2. 프론트·백엔드가 계약을 바꿔야 하면 **코드보다 `contract-stage-<N>.md`를 먼저 갱신**하고 `tech-lead` 승인을 받는다.
3. 다른 에이전트에게 요청·질문이 있으면 해당 문서에 `> TO: <agent>` 블록으로 남긴다.
4. 여기 문서는 **작업 중 상태**다. 단계가 끝나면 결과 요약을 `complete-work/`로 옮기고 여기 문서는 남겨 이력으로 둔다.

## 문서 템플릿

```markdown
# <제목> — Stage <N>
- 작성: <agent> / <YYYY-MM-DD>
- 상태: 초안 | 검토중 | 확정

## 배경
## 내용 (타입 정의 / 스키마 / 결정)
## 다른 에이전트에 대한 요청
> TO: <agent> — <요청 내용>
## 미결 항목
```
