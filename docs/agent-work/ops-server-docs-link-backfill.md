## 0. 목적과 원칙

이미 서버에 있는 문서들은 `[[문서명]]` 링크 없이 올라와 그래프에서 대부분 고립된 점이다.
이 작업은 **문서 내용은 그대로 두고 관련 문서 링크만 더해** 백링크·그래프가 실제 지도가 되게 한다.

| 원칙 | 이유 |
| :--- | :--- |
| **링크만 더한다.** 문장 수정·재작성·서식 정리 금지 | 서버 문서는 사용자 원본이다 |
| **배치마다 사람 승인** 후에만 저장 | 잘못된 연결은 그래프를 오히려 오염시킨다 |
| 저장은 반드시 `mdws.sh put` (baseMtime) | 그사이 사람이 고친 문서는 409로 거부되어 덮어쓰지 않는다(불변식 5) |
| 파일 시스템에 직접 쓰지 않는다 | API를 거쳐야 atomic write·버전 백업·색인 갱신이 함께 일어난다 |
| 추측으로 없는 문서를 링크하지 않는다 | "아직 없는 문서" 유령 노드가 늘어난다 |

## 4. 배치 1회 절차

### 4-1. 내려받기와 후보 찾기

배치의 문서마다:

```bash
SUB="proj/작업 기록 1005.md"; F="$WORK/$(echo "$SUB" | tr '/ ' '__')"
bash Example/mdws.sh get "$SUB" "$F"          # + "$F.mtime"
cp "$F" "$F.orig"
bash Example/mdws.sh links "$SUB"              # 이미 있는 링크 — 다시 달지 않는다
```

후보는 이 순서로 찾는다.

1. **같은 폴더(프로젝트) 문서** — `bash Example/mdws.sh list "<폴더>/"`
2. **본문이 언급하는 대상** — 문서의 고유명사·기능명·문서 제목으로 검색 (검색어 **3자 이상**)
   ```bash
   bash Example/mdws.sh search "라이트맵 베이크"   # 첫 열이 붙여 쓸 링크 ([[이름]] 또는 [[폴더/이름]])
   ```
3. **날짜형 작업 기록**이면 같은 프로젝트의 직전 작업 기록 · 설계 문서 · 할 일 문서

### 4-2. 연결 판단 기준

| 연결한다 | 연결하지 않는다 |
| :--- | :--- |
| 본문이 그 문서의 내용·결정·작업을 **직접 언급**한다 | 키워드만 겹친다 |
| 같은 기능의 설계 ↔ 작업 기록 ↔ 할 일 | 모든 문서를 한 "허브" 문서에 연결 |
| 직전 작업 기록 (시간순 사슬) | 아직 없는 문서를 추측으로 |
| 원인 ↔ 해결 문서 (버그 보고 ↔ 수정 기록) | 자기 자신 |

- 문서당 **새 링크는 8개 이하**. 넘으면 가장 직접적인 것만 남긴다.
- 확신이 없으면 연결하지 않고 승인 표의 "보류"에 적는다.

### 4-3. 링크 넣는 방법 (사본 `$F`에만)

- **본문 언급 자리**: 이미 문서 이름을 그대로 쓴 곳이면 그 단어를 `[[이름]]`으로 감싼다.
  표현이 다르면 `[[이름|본문에 있던 표현]]`. **단어를 바꾸거나 문장을 늘리지 않는다.**
- **그 밖의 연결**: 문서 맨 끝에 섹션을 하나 더한다. 이미 `## 관련 문서`가 있으면 그 목록에 항목만 추가한다.
  ```markdown

  ## 관련 문서

  - [[설계]] — 이 작업이 반영한 설계
  - [[작업 기록 1004]] — 직전 작업
  ```
- **건드리지 않는 곳**: frontmatter, 코드 블록·인라인 코드(그 안의 `[[…]]`는 링크로 인식되지도 않는다), 표 구조
- 같은 이름이 여러 폴더에 있으면 `search`가 주는 `[[폴더/이름]]` 형식을 그대로 쓴다

### 4-4. 승인 게이트 ★ (배치마다)

저장 전에 사용자에게 **표와 diff**를 보여주고 승인을 받는다.

```bash
diff -u "$F.orig" "$F"        # 문서마다. + 줄만 있어야 정상(본문 단어 감싸기는 같은 줄 교체 1건)
```

| 문서 | 추가 링크 | 위치 | 근거(본문 문장 또는 이유) |
| :--- | :--- | :--- | :--- |
| proj/작업 기록 1005.md | `[[설계]]` | 본문 2행 | "설계를 반영했다" |
| | `[[작업 기록 1004]]` | 관련 문서 | 직전 작업 |
| (보류) | `[[아이디어]]`? | — | 언급이 모호 |

- 사용자가 빼라고 한 링크는 사본에서 지우고 diff를 다시 보여준다
- **승인 전에는 `put`하지 않는다**

### 4-5. 저장

```bash
bash Example/mdws.sh put "$SUB" "$F"
echo -e "$(date +%FT%T)\t$SUB\tok" >> "$WORK/applied.log"
```

| 결과 | 조치 |
| :--- | :--- |
| `✓ 저장` | 다음 문서 |
| `✗ 충돌(409)` | 그사이 누가 고쳤다. **덮어쓰지 않는다.** `get`부터 다시 하고 diff를 새로 승인받는다 |
| 401 | `rm -f "$MDWS_COOKIE_JAR"` 후 재실행(재로그인) |
| 429 | 1분 기다렸다가 같은 문서 재시도 |
| 그 밖 | 중단하고 사용자에게 보고 |

### 4-6. 배치 확인

```bash

```

## 6. 되돌리기

| 범위 | 방법 |
| :--- | :--- |
| 문서 1건 | 같은 폴더의 직전 버전 파일(`이름_YYYYMMDD-HHmmss.md`, 파일 카드의 버전 목록에서 확인) 내용으로 다시 저장 — 아래 |
| 전체 | 서버 중지 → `~/MarkdownDocs`를 2절 백업으로 복원 → 서버 기동(증분 색인이 다시 맞춘다) |

```bash
# 문서 1건 되돌리기 — 뷰어에 "복원" 버튼은 없다. 직전 버전 내용을 현재 문서로 다시 저장한다.
bash Example/mdws.sh get "proj/이름_20261005-120000.md" "$WORK/old.md"
bash Example/mdws.sh get "proj/이름.md" "$WORK/cur.md"          # 현재 mtime 확보 (cur.md.mtime)
cp "$WORK/old.md" "$WORK/cur.md"
bash Example/mdws.sh put "proj/이름.md" "$WORK/cur.md"
```
